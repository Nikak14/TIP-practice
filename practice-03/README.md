## Эксперименты

| Опыт | Прогноз | Результат и причина |
|---|---|---|
| Отсутствующий элемент и коллекция | `null` и длина `0` | `querySelector` даёт `null`, `querySelectorAll` — пустой `NodeList`. |
| `dataset.taskId` | Строка `"23"`; после `Number` число `23` | Атрибуты DOM читаются как строки, поэтому id преобразуется на границе обработчика. |
| Добавить две записи | Сохранённый `NodeList` останется длиной `1`, новый запрос покажет `3` | `querySelectorAll` возвращает статическую коллекцию. |
| Строка с HTML | В заголовке видны символы `<strong>…</strong>` | Использован `textContent`; элемент `strong` не создаётся. |
| Нажать вложенный `span` | Захват → кнопка → всплытие | `target` — вложенный `span`; `currentTarget` меняется от контейнера к кнопке и обратно; фазы `1`, `3`, `3`. |

## Организация приложения

`task-selectors.js` возвращает новый массив видимых задач. `task-view.js` создаёт карточки через DOM и `textContent`, перерисовывает список, сводку и пустое состояние. `main.js` хранит текущий список и фильтр, подписывает контейнеры один раз, вызывает сервисные функции и возвращает фокус после перерисовки. Выбор фильтра меняет отображение, а не полный массив или общий прогресс.

## Отладка и вывод

В `handleTaskListClick` можно поставить точку останова на чтении `dataset.taskId`: до `Number` значение — строка, после — числовой id. Для действия `toggle` по `id = 4` находится задача с `completed: false`, сервис возвращает новый массив, а `renderApp` обновляет карточку и сводку. Штатные браузерные проверки также подтвердили отказ для `777` и `4abc` без повреждения списка и сохранение фокуса. Скриншот именно остановленного DevTools следует сделать вручную при защите.

В ПР3 действие проходит путь «событие → сервис → новое состояние → DOM». Дополнительное необязательное расширение не выполнялось.
