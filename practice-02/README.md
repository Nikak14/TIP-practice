## Модель и организация

Задача имеет положительный безопасный целый `id`, уникальный в списке; нормализованное название длиной 1–100; логический `completed`; приоритет `low`, `medium` или `high`. `id` не является индексом массива: например, задача `id = 4` расположена на второй позиции.

`src/data.js` хранит общий и индивидуальный наборы. `src/task-service.js` содержит девять чистых функций чтения и изменения задач. Успешное создание возвращает `{ ok: true, task }`, успешные операции над списком — `{ ok: true, tasks }`, ожидаемый отказ — `{ ok: false, error }`. Изменения возвращают новый массив; при обновлении выбранный объект тоже создаётся заново. `getTaskStats` возвращает числовой `progress`, чтобы округлять его только при выводе в `src/main.js`.
