## Запуск

Из корня репозитория последовательно выполнить:

```bash
node practice-01/js/hello.js
node practice-01/js/types.js
node practice-01/js/progress.js
node practice-01/js/plan.js
node practice-01/js/debug.js
```

Для браузера открыть `practice-01/index.html` и DevTools → Console. В `index.html` подключён `hello.js`; для проверки других файлов по одному заменить значение `src` на нужный путь `./js/имя.js`. Вывод идёт в консоль, а не на страницу. `typeof document` в Node.js дал `undefined`; в браузере при обычной загрузке страницы доступен объект `document`.

## Типы и преобразования

Прогноз перед запуском совпал с фактическим выводом `node practice-01/js/types.js`:

| Выражение | Прогноз | Факт | Тип результата | Объяснение |
|---|---|---|---|---|
| `"8" + 2` | `"82"` | `"82"` | string | `+` соединяет строку с числом. |
| `"8" - 2` | `6` | `6` | number | Вычитание преобразует строку в число. |
| `Number("8") + 2` | `10` | `10` | number | Выполнено явное преобразование. |
| `"12" > "3"` | `false` | `false` | boolean | Две строки сравниваются по символам. |
| `12 === "12"` | `false` | `false` | boolean | Строгое сравнение учитывает тип. |
| `Number("")` | `0` | `0` | number | Пустая строка при числовом преобразовании даёт ноль. |
| `Number("text")` | `NaN` | `NaN` | number | Строка не является числом. |
| `Boolean("false")` | `true` | `true` | boolean | Любая непустая строка истинна. |
| `typeof null` | `"object"` | `"object"` | string | Историческая особенность оператора `typeof`. |
| `typeof NaN` | `"number"` | `"number"` | string | `NaN` относится к числовому типу. |

## Сводка и план

Для варианта 8: `totalTasks = 14`, `completedTasks = 4`, `dailyLimit = 4`. Фактическая сводка: **осталось 10**, прогресс **28.6%**, статус **«В работе»**. План через `while`: день 1 — 4 задачи, день 2 — 4, день 3 — 2; **всего 3 дня**.

Проверены по 10 входных наборов для `progress.js` и `plan.js`, включая ноль, полностью выполненный список, превышение числа выполненных задач, дробные значения, строки и выход за границу. Все 20 случаев дали ожидаемый результат. Для общего примера `12, 5, 3` план вывел три дня с последним днём из одной задачи. При недопустимых данных выводится одно сообщение `Ошибка:` и расчёт не продолжается.

## Отладка

Исходный ошибочный код давал `"32"`, `-24` и `6`: строки складывались как текст, а цикл не включал число 4. После явного `Number()` и условия `taskNumber <= 4` фактический вывод: **5**, **3**, **10**. Для демонстрации в DevTools точку останова следует поставить на строке вычисления `completedTotal` в `js/debug.js`; проверить типы исходных переменных до шага и результат после шага. Скриншот именно остановленного отладчика необходимо сделать вручную при защите.
